# CODSOFT_TASK2 — Smart To-Do List

A responsive task management web app built for Task 2 of the CodSoft Frontend Development internship.

## Live Demo
https://marishasv.github.io/CODSOFT_TASK2/

## Features
- Add, edit, delete, and mark tasks as complete
- Priority levels (Low / Medium / High)
- Optional due dates for each task
- Live search and filter (All / Pending / Done)
- Task counts (Total, Pending, Completed)
- Data persists after refresh using Local Storage
- Fully responsive design

## Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
